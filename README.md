# Next Chapter — Career Resource Center

A responsive career resource center template with neutral content placeholders, original SVG graphics, animation, a clickable pathway, and a planning checklist.

## Publish With GitHub Pages

1. Create a GitHub repository for this website.
2. Upload the files in this folder to the repository root. The page file should be at the root level as `index.html`.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push this repository to the **main** branch.
6. The workflow in `.github/workflows/deploy-pages.yml` will build and deploy the site automatically.
7. After the workflow runs, open the Pages link shown in GitHub to see the published site.

The standard address uses your GitHub username and repository name on the github.io domain. A custom domain can be configured separately in Pages settings.

## Edit in VS Code and Sync to GitHub

- Open this project directly in VS Code.
- Make your edits to the HTML, CSS, and content in the files here.
- Save your changes.
- Commit them in GitHub or the VS Code Source Control view.
- Push to the repository's **main** branch.
- GitHub Actions will automatically deploy the updated website.

## Edit the Template

Open `index.html` in a text editor. Styles are in the `<style>` block. Section labels and content placeholders are in the `data` object in the `<script>` block. Home page content and the original illustration are in the HTML above the script.

No build step, package installation, external scripts, external fonts, API keys, or authentication service is required. Internal navigation uses URL fragments, allowing the template to work at both a repository subpath and a custom domain. Checklist state resets when the page reloads.
